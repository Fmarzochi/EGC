# EGC Scrubber specification

The Scrubber removes AI provenance marks from content you own, automatically and
across every supported tool. It ships with EGC and turns on at `egc init`, the
same way the Crusher does. This document is the design contract.

## Goals

- Automatic, deterministic hygiene with no command to invoke.
- Verifiable removals only in the guaranteed layer; statistical marks are
  best-effort and never claimed undetectable.
- Additive and safe: it never touches the installer, and it fails open so a
  crash can never block or corrupt a write.

## Components

| Component | File | Role |
| --- | --- | --- |
| Engine | `scripts/lib/scrubber/engine.js` | `inspect` and `clean` over text |
| Codepoint tables | `scripts/lib/scrubber/unicode-marks.js` | classification and preservation rules |
| Dash normalizer | `scripts/lib/scrubber/dash-normalize.js` | long dashes to safe punctuation |
| Binary guard | `scripts/lib/scrubber/binary-guard.js` | refuse binary as text; text-extension allowlist |
| Co-author stripper | `scripts/lib/scrubber/coauthor-strip.js` | remove AI trailers, keep humans |
| Container metadata | `scripts/lib/scrubber/container-meta.js` | strip AI provenance from Markdown/HTML/SVG |
| Write hook | `scripts/hooks/scrubber-hook.js` | clean Write/Edit/MultiEdit content |
| Commit hook | `scripts/hooks/scrubber-precommit.js` | strip AI co-authorship in commit messages |
| Manual CLI | `scripts/hooks/scrubber-cli.js` | on-demand inspect/clean |
| Skill | `skills/security/content-scrubber/` | manual/batch mode and honest reporting |

## Guaranteed layer (deterministic, verifiable)

- Invisible Unicode carriers (zero-width family, word joiner, BOM, bidi controls
  that are not legitimate, tag characters, variation selectors, private-use,
  soft hyphen, interlinear annotation).
- Space look-alikes normalized to U+0020.
- Cross-script letter look-alikes (aggressive mode).
- Long dashes to safe punctuation; numeric ranges to an ASCII hyphen.
- AI co-authorship / "generated by AI" commit trailers.

### Preservation rules

The engine keeps load-bearing invisibles: emoji joiners and variation selectors,
script joiners inside complex scripts, complete flag tag sequences, same-script
fillers (Mongolian FVS, Khmer inherent vowels, Hangul fillers), RTL directional
marks, and paired bidi embeddings. Overrides and free-floating carriers are
stripped. `inspect` is diagnostic and reports bidi controls even though `clean`
preserves the legitimate ones by default.

## Best-effort layer

Statistical token-sampling text marks are handled only by the rewrite workflow in
the skill. No model is bundled and no undetectability is claimed.

## Out of scope

Pixel/audio/video watermarks, C2PA soft binding, and model backdoors.

## Safety contract

- Fail-open everywhere: parse errors, engine errors, or binary input result in
  the original content passing through untouched.
- The write hook only cleans files with a known text extension and non-binary
  content.
- The ASCII hyphen-minus and the mathematical minus sign are never altered.
- The commit hook keeps human co-authors and removes only AI attribution.

## Non-conflict with the Crusher

The Crusher rewrites Bash commands; the Scrubber cleans file content (Write/Edit)
and commit messages. They act on different tool events and never contend for the
same input. Both live in the coordinated hook chain, each independently
toggleable by profile.

## Rollout

The engine and hooks install through the existing `hooks` module
(`scripts/hooks`, `scripts/lib`); the skill installs through the `skills` module.
Nothing in the install engine changes. Tools that support hooks get the automatic
behavior; all tools get the manual skill.
